## 1. 개요 (Overview)

### 1.1 제품 한 줄 정의
> 2000년대 초반 유행어부터 최신 Gen Z 신조어까지, 글자 조각을 조합해 정답을 맞히는 캐주얼 단어 퍼즐 게임

### 1.2 배경 및 기회
- 출퇴근·등하교 중 스마트폰 사용자의 대부분은 **5~15분 이내 단시간 콘텐츠**를 소비
- 기존 단어 퍼즐 게임(Word Tower 등)은 일반 어휘 기반으로, **세대 공감 요소**가 없음
- 20~30대는 유행어·밈 문화에 높은 관심을 보이며, **"나 이거 알아?" 라는 확인 욕구**가 강함
- 신조어는 지속적으로 생성되어 **콘텐츠 업데이트가 자연스럽게 재방문 동기**로 연결됨

### 1.3 목표
- MVP(웹): 핵심 게임 루프 검증 및 데모 시연 가능 수준
- 이후: iOS / Android 앱으로 확장

## 2. 타겟 사용자 (Target Users)

### Primary User
- **연령:** 20~30대
- **특성:** 유행어·신조어·밈 문화에 민감하고 트렌드를 잘 아는 세대
- **사용 맥락:** 버스·지하철 등 대중교통 이용 중 **짧은 시간(5~10분) 동안 간단히** 즐기는 캐주얼 게임
- **동기:** 유행어를 알아맞히는 성취감, 세대별 유행어를 통한 공감·향수

### User Persona
> 직장인 김지은(28세). 매일 지하철로 40분 출퇴근. 짧은 게임으로 스트레스 해소를 즐기며, 인스타그램 밈 계정을 팔로우할 만큼 유행어에 밝음. 친구들과 "이거 알아?" 하며 공유하는 것을 좋아함.

## 3. 핵심 기능 (Core Features)

### 3.1 게임 메커니즘

#### 기본 플레이
- 화면에 **유행어를 구성하는 글자 조각(자모 또는 음절)** 이 무작위 순서로 제공됨
- 사용자가 글자를 조합해 **정답 유행어/신조어**를 완성
- 정답 시 다음 단어로 자동 진행

#### 레벨 시스템
- **단어 길이 = 난이도** 기준으로 레벨 구분
  - 예: Lv.1~5 (2~3글자) → Lv.6~10 (4~5글자) → Lv.11~ (6글자 이상)
- 문제는 **랜덤 출제** (시대 구분 없이 2000년대~현재 혼합)

#### 힌트 시스템
| 힌트 단계 | 내용 | 조건 |
|-----------|------|------|
| 힌트 1 | 해당 유행어가 쓰이던 **시대 및 사용 상황 설명** | 힌트 버튼 1회 탭 |
| 힌트 2 | 정답의 **첫 글자 공개** | **광고 시청(15~30초)** 후 해제 |

### 3.2 문제 데이터베이스

- MVP 기준 **10~20개** 유행어/신조어 수록
- 예시 카테고리 (시대별 혼합 출제)
  - 2000년대 초: 엽기, 대박, 짱, 뻔뻔, 된장녀 등
  - 2010년대: 멘붕, 극혐, 솔까말, 인싸/아싸 등
  - 2020년대 Gen Z: 갓생, 스불재, 억텐, 킹받다, 뇨르다 등
- 이후 **주기적 업데이트**로 신조어 지속 추가

### 3.3 성취 시스템 (배지/스탬프)

| 레벨 달성 | 보상 |
|-----------|------|
| Lv. 5 클리어 | 🏅 "유행어 입문자" 배지 |
| Lv. 10 클리어 | 🥈 "밈 중급자" 배지 |
| Lv. 15 클리어 | 🥇 "신조어 고인물" 배지 |

- 획득한 배지는 **프로필/배지함**에서 확인 가능
- 성취 욕구를 자극하여 **레벨 진행 동기 부여**

### 3.4 광고 수익화

- **배너 광고:** 게임 화면 하단 상시 노출
- **전면 광고(Interstitial):** 일정 스테이지 클리어 후 노출 (예: 5스테이지마다)
- **보상형 광고(Rewarded Ad):** 힌트 2 요청 시 광고 시청 → 첫 글자 공개

## 4. 사용자 흐름 (User Flow)

```
앱/웹 진입
    │
    ▼
메인 화면 (현재 레벨 표시 + 시작 버튼)
    │
    ▼
게임 화면
  ┌─────────────────────────────────┐
  │  [레벨 표시]  [배지 현황]        │
  │                                 │
  │  [ 글 ] [ 자 ] [ 조 ] [ 각 ]    │  ← 글자 조각 (랜덤 배치)
  │                                 │
  │  정답 입력창: [_ _ _ _]         │
  │                                 │
  │  [힌트 1 버튼]  [힌트 2 버튼]   │
  └─────────────────────────────────┘
    │                    │
    │ 정답               │ 오답
    ▼                    ▼
클리어 화면         재시도 또는 힌트 사용
  │
  ▼
배지 달성 조건 충족 시 → 배지 획득 팝업
  │
  ▼
다음 레벨로 진행
```

## 6. MVP 제외 범위 (Out of Scope)

> MVP 검증에 불필요하거나 개발 복잡도를 높이는 기능은 모두 제외합니다.

| 제외 기능 | 제외 이유 |
|-----------|-----------|
| iOS / Android 네이티브 앱 | 웹 MVP 검증 후 다음 단계로 |
| 회원가입 / 로그인 / 소셜 로그인 | MVP에서는 로컬 저장으로 충분 |
| SNS 공유 기능 | 게임 재미 자체를 먼저 검증 후 추가 |
| 랭킹 / 리더보드 | 서버 인프라 필요, MVP 불필요 |
| 데일리 챌린지 | 서버 스케줄링 필요, 복잡도 증가 |
| 유저 프로필 커스터마이징 | 핵심 가치와 무관 |
| 멀티플레이 / 대전 모드 | MVP 범위 초과 |
| 미디어 힌트 (영상/밈 이미지) | 저작권 이슈 + 개발 복잡도 높음 |
| 인앱 결제 / 광고 제거 유료화 | 수익 검증은 광고 모델로 우선 |
| 시대별 챕터 분류 UI | 랜덤 출제로 단순화 |
| 푸시 알림 | 웹 MVP 단계에서 불필요 |
| 다국어 지원 | 한국어 단일 버전으로 시작 |

## 7. 기술 스택 제안 (MVP)

| 영역 | 제안 기술 | 이유 |
|------|-----------|------|
| 프론트엔드 | React (또는 Vanilla JS) | 웹 MVP에 최적, 이후 React Native 전환 용이 |
| 스타일링 | Tailwind CSS | 빠른 UI 구성 |
| 데이터 저장 | LocalStorage | 서버 없이 진행 상황 저장 |
| 광고 | Google AdSense / AdMob (웹) | 가장 빠른 광고 연동 |
| 호스팅 | Vercel / Netlify | 무료, 빠른 배포 |
| 문제 DB | JSON 파일 (정적) | MVP 단계에서 서버 불필요 |
